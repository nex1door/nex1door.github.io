кодекс

// инженерия

  • Fail fast — ошибка должна кричать, а не шептать в лог.
  • Observability — метрики и трейсинг с первого дня, не «потом».
  • Идемпотентность — повторный запрос не должен ломать мир.

// эксплуатация

  • Infrastructure as code — руками только в крайнем случае.
  • Бэкапы проверяются восстановлением, иначе их нет.
  • Simple > clever — код читают чаще, чем пишут.
